CS101: Introduction to Web Development

Credits: 4.0 Units | Semester: Fall 2024

Course Description

This course provides a comprehensive introduction to the fundamentals of web development. Students will learn to structure content with HTML, style interfaces with CSS, and understand the core principles of responsive web design.
